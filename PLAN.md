# Implementation Plan: Knowledge Graph News App

## Обзор
План реализации приложения для хранения новостных статей с извлечением понятий и визуализацией в виде графа.

**Цель MVP:** За 1 час реализовать базовый функционал: добавление статьи → AI-анализ → просмотр графа.

## MVP Scope

**Входит в MVP (High priority stories):**
- STORY-001: Импорт статей
- STORY-002: Извлечение понятий (AI)
- STORY-003: Сохранение в БД
- STORY-004: Визуализация графа
- STORY-005: Навигация по графу

**После MVP (Medium/Low priority):**
- STORY-006: Фильтрация
- STORY-007: Поиск связей

## Команды запуска

```bash
# Установка зависимостей
npm install express better-sqlite3 cors

# Запуск Ollama (требуется установленный Ollama)
ollama serve
ollama pull llama3.2

# Запуск сервера
node server.js

# Сборка фронтенда (в другом терминале)
npm run build

# Режим разработки
npm run dev
```

## Критерии готовности MVP

- [ ] Можно добавить статью через форму
- [ ] AI извлекает понятия и показывает их для подтверждения
- [ ] Статья и понятия сохраняются в SQLite
- [ ] Граф отображает все статьи и понятия
- [ ] При клике на узел показываются детали
- [ ] Приложение работает полностью локально
