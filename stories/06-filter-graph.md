# STORY-006: Фильтрация по темам/понятиям

## ID
`STORY-006`

## Секция
Работа с графом

## Описание
Как разработчик, я хочу фильтровать граф по понятиям, чтобы сфокусироваться на нужной области знаний.

## Критерии приёмки
- [ ] Выпадающий список всех понятий в системе
- [ ] При выборе понятия граф показывает только связанные статьи
- [ ] Кнопка "Сбросить фильтр" возвращает полный граф
- [ ] Поиск по названию понятия
- [ ] Счётчик статей для каждого понятия

## Приоритет
Medium

## Зависимости
- STORY-004 (Визуализация графа)
- STORY-005 (Навигация по графу)
