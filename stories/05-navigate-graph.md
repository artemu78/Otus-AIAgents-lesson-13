# STORY-005: Навигация по узлам графа

## ID
`STORY-005`

## Секция
Работа с графом

## Описание
Как разработчик, я хочу кликать на узлы графа, чтобы видеть детали и связи выбранного элемента.

## Критерии приёмки
- [ ] При клике на узел статьи показываются её детали (заголовок, источник, резюме)
- [ ] При клике на узел понятия подсвечиваются все связанные статьи
- [ ] Можно приближать/отдалять граф (zoom)
- [ ] Можно перетаскивать узлы для лучшего расположения
- [ ] Сброс view возвращает начальное состояние

## Приоритет
High (MVP)
