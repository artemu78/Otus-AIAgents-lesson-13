# STORY-007: Поиск связей между статьями

## ID
`STORY-007`

## Секция
Анализ и инсайты

## Описание
Как разработчик, я хочу находить статьи, связанные через общие понятия, чтобы открывать новые взаимосвязи.

## Критерии приёмки
- [ ] Поиск показывает статьи с общими понятиями
- [ ] Результаты сортируются по количеству общих понятий
- [ ] Показывается список общих понятий между статьями
- [ ] Можно перейти из результатов поиска в граф

## Приоритет
Medium

## Зависимости
- STORY-004 (Визуализация графа)
