# STORY-004: Визуализация графа связей

## ID
`STORY-004`

## Секция
Работа с графом

## Описание
Как разработчик, я хочу видеть интерактивный граф связей между статьями и понятиями, чтобы визуально понимать структуру знаний.

## Критерии приёмки
- [ ] Граф отображается на главной странице приложения
- [ ] Узлы статей имеют один цвет/форму
- [ ] Узлы понятий имеют другой цвет/форму
- [ ] Связи отображаются линиями между узлами
- [ ] Граф автоматически располагается (layout) для читаемости
